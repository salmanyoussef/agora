# AGORA — public reviewer demo deployment (ICSOC 2026)

Deploys the full AGORA stack to [Render](https://render.com) so reviewers can use the
system at a public URL. Branch: `deploy/reviewer-demo`.

## Topology

| Service | Type | Exposure | Contents |
|---|---|---|---|
| `agora-backend` | Web service (Docker) | **Public** | FastAPI + agent pipeline + frontend (served at `/`) |
| `agora-weaviate` | Private service (Docker) | Internal only | Weaviate 1.36.0, pre-seeded with the ~73k-dataset catalogue index |

Weaviate is **never** publicly reachable: it is a Render *private service*, addressable
only from other services in the same Render workspace (`http://agora-weaviate:8080`,
gRPC `agora-weaviate:50051`).

## Data seeding

`src/infra/weaviate-seeded/Dockerfile` bakes the pre-embedded catalogue
(`weaviate_backup.tar.gz`, a tar of Weaviate's data directory) into the image at build
time, downloading it from `SEED_URL` (a GitHub release asset). No persistent disk, no
runtime restore step; every deploy starts from the same snapshot. To refresh the
catalogue, run an admin-gated `/ingest/sync/stream`, or produce a new backup tarball and
update the release asset.

## Public-demo hardening (new in this branch)

- **Rate limiting** (`slowapi`, per client IP, X-Forwarded-For aware) on `/search` and
  `/search/stream`: default `3/minute;20/hour;60/day`, override via `AGORA_RATE_LIMIT`.
- **Cost circuit-breaker** (`app/services/budget.py`): every pipeline run's estimated
  USD cost (existing per-run cost estimation) accumulates in `AGORA_BUDGET_FILE`
  (on the persistent disk, survives restarts). Once `AGORA_COST_CEILING_USD`
  (default 10) is reached, search requests get a graceful bilingual "budget exhausted"
  message. Runs with unknown pricing are charged a $0.02 flat fallback. Check status at
  `GET /budget`; reset by deleting the budget file or raising the ceiling.
- **Concurrency cap**: at most `AGORA_MAX_CONCURRENT` (default 3) simultaneous pipeline
  runs; excess requests get a "demo is busy" message.
- **Admin gating**: `/ingest`, `/ingest/sync/stream`, `/debug/*` require the
  `X-Admin-Token` header matching `AGORA_ADMIN_TOKEN` (auto-generated by Render).
- **Secrets**: Azure OpenAI endpoint/key and `SEED_URL` are `sync: false` in
  `render.yaml` — set them in the Render dashboard; nothing is committed.
- `AGORA_DEMO_MODE=true` keeps Technical runs fast (fewer RLM iterations, capped datasets).

## Deploying

1. Push this branch to GitHub and upload `weaviate_backup.tar.gz` as a release asset.
2. Render → New → Blueprint → select the repo/branch; Render reads `render.yaml`.
3. Fill in the `sync: false` env vars (Azure endpoint + key, `SEED_URL`).
4. Deploy; wait for `agora-weaviate` (long image build: ~1.6 GB seed), then `agora-backend`.
5. Verify: `GET /health`, `GET /budget`, then ask a question at the public URL in both
   General and Technical modes; confirm `GET /debug/count` (with admin token) ≈ 73,860.

## Costs (approximate, July 2026)

- Render: 2 × Standard instance ($25/mo each) + 1 GB disk ($0.25/mo) ≈ **$50/mo**,
  prorated per second — spin down after the review period.
- Azure OpenAI: bounded by the circuit-breaker ceiling (**$25 total** by default).

## Teardown after the review period

Render dashboard → each service → Settings → **Delete service** (or suspend to keep
config). Delete the GitHub release asset if the backup should not stay public.

## Azure Container Apps (chosen path for the ICSOC demo)

Render blueprint above is kept as a portable alternative; the live demo runs on
**Azure Container Apps** (free via Azure credits). Topology differs slightly:
one Container App with **two containers in the same replica** — the FastAPI backend
(public ingress on :8000) and Weaviate as a **localhost sidecar** (no ingress at all,
so it is unreachable from outside by construction). The catalogue index is baked into
the Weaviate image (`src/infra/weaviate-seeded/Dockerfile.aca`, `ADD` of the backup
tarball) and built in the cloud with ACR Tasks — no local Docker needed.

Reproducible runbook: `src/infra/aca/aca_deploy.sh` + `containerapp.yaml.template`
(resource group `agora-demo-rg`, region `francecentral`, 2 vCPU / 4 GiB fixed at
1 replica, Azure Files share mounted at `/data` for the budget counter).

Teardown: `az group delete -n agora-demo-rg --yes` removes everything.
